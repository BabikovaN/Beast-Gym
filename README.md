# AURELITH Fitness Club — сайт преміального фітнес-клубу

Сучасний сайт залу в біло-сіро-золотій гамі: головна, клуб і зони, тарифи, персональні тренування й спецпропозиції, фітнес-бар, правила, вакансії, контакти та запис на пробне тренування.

## Як змінити вміст
Усі тексти, ціни, графік і контакти — у файлі `js/data.js`:
- `CLUB` — назва, телефон, Telegram/Viber/WhatsApp, Instagram, адреса, графік;
- `PLANS`, `PERSONAL`, `OFFERS` — абонементи, персональні тренування, акції;
- `BAR` — фітнес-бар; `RULES` — правила; `JOBS` — вакансії; `ZONES`, `AMENITIES` — зони й переваги клубу.

## Запис на пробне тренування
Відвідувач заповнює форму (ім'я, телефон, мета, зручний час) і надсилає заявку в WhatsApp / Viber (текст уже вставлено) або Telegram, чи телефонує. Номери беруться з `CLUB` у `js/data.js` — **замініть демо-контакти на справжні**.

## Фото
Фото інтер'єру згенеровані штучним інтелектом для демонстрації дизайну. Перед запуском замініть їх реальними фото клубу (`assets/img/`).

## Запуск
Статичний сайт без збірки: `python -m http.server 8000` → http://localhost:8000. Для GitHub Pages достатньо опублікувати гілку `main`.
